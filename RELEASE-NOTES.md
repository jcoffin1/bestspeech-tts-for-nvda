# BeSTSpeech TTS for NVDA 2026.2.2

- Restores the speech engine, wrapper, and 32-bit helper missing from the 2026.2.1 download.
- Allows in-memory synthesis without a physical audio device, including on headless Windows machines.
- Includes dependency license notices and excludes generated Python cache files.
- Stops release builds immediately if compilation, audio regression tests, or package validation fail.
- Updates the add-on's support link to this repository.

Requires NVDA 2026.2 or later. Automated driver, native audio, cancellation, and package checks cover this release; live NVDA interaction still needs user testing.
